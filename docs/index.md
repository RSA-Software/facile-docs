# Manuale Facile

Benvenuto nella guida operativa di **Facile**, il gestionale di R.S.A. per la
piccola e media impresa.

Il manuale è organizzato **una scheda per ogni maschera** del programma: per
ciascuna trovi a cosa serve, il significato di ogni campo, i comandi
disponibili e le procedure passo passo per le operazioni più frequenti.

## Come cercare

Usa il campo di ricerca in alto: funziona sul testo di tutte le pagine, quindi
puoi cercare il **nome esatto di un campo**, l'etichetta di un pulsante o il
testo di un messaggio di errore che ti è comparso a video.

!!! tip "Suggerimento"

    Ogni pagina ha un indice laterale con le sezioni: per andare direttamente
    ai campi o ai messaggi di errore, usa quello invece di scorrere.
